## 为何当前安装仍为 PARTIAL

受测安装的 user-approval 构建包含自动许可改装，sandbox 构建包也绕过升级拒绝。因此当前安装不会按源码原有方式询问，不能从“没有事件”判定控制器完整审批通过。控制器保留这个原生行为，没有修改外部安装来制造通过结果。

SOURCE_FIXTURE 在独立测试进程里，仅将这两个包从安装内已有 TypeScript 源码编译并加载；保留原生模块解析，其余 Host 使用原构建。原始源码与编译 fixture 的 12 份文件哈希列在结果中。它实际证明 CLI 可经原生 waterfall 处理允许/拒绝，**不等于当前改装安装已经恢复审批**。普通产品运行不使用此加载器。

独立审阅复现并推动修复了发送/停止并发、Host 别名重复绑定、旧观察覆盖完成状态；对应回归在本地测试中。原生 UI 的 HTTP 200 只证明服务保留，不是浏览器视觉和所有交互 E2E。
